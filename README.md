# T-SQL Fundamentals – Study Notes & Practical Exercises

## About This Repository

This repository documents my learning journey through **T-SQL Fundamentals** by Itzik Ben-Gan.

The goal is to build a strong foundation in Transact-SQL (T-SQL), understand SQL Server concepts, and develop practical skills essential for data analytics and data engineering.

Rather than simply collecting notes, I focus on understanding concepts through hands-on SQL queries, practical examples, exercises, and real-world scenarios.

## Learning Objectives

- Understand SQL Server architecture and relational database concepts.
- Master T-SQL syntax and query fundamentals.
- Develop strong skills in data retrieval, filtering, sorting, and aggregation.
- Understand different types of joins and subqueries.
- Work with CTEs, temporary tables, views, and table expressions.
- Practice data modification using INSERT, UPDATE, DELETE, and MERGE.
- Explore SQL Server functions, variables, and control flow.
- Improve query-writing skills and problem-solving techniques.
